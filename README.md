# Elemental Priston Tale — cliente web

Este repositório é dedicado ao novo cliente web do **Elemental Priston Tale**, desenvolvido com Three.js, TypeScript e Vite.

O trabalho em andamento está na VM StormPT, em `C:\Elemental Priston Tale\web-client`. A prévia local já carrega mapas originais, personagens e animações; autenticação, criação de personagens e sistemas completos do jogo ainda estão em desenvolvimento. O domínio `stormpt.hoststorm.cloud` permanece reservado para uma publicação futura após validação.

Os arquivos originais do cliente, recursos convertidos, dados de jogadores, credenciais e builds não são publicados neste repositório. `Cliente` e `Source` são referências locais somente de leitura. O projeto anterior baseado em `sungam3d/priston-tale-web` foi retirado da branch principal. Seu histórico anterior pode ser recuperado na branch [backup/priston-tale-web-2026-10-28](https://github.com/danilostorm/pristonweb/tree/backup/priston-tale-web-2026-10-28).

## Estado
